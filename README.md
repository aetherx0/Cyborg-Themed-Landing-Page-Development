# Cyborg-Themed-Landing-Page-Development
Seam: Cyborg-Themed Landing Page

A responsive landing page for Seam, a fictional human-augmentation clinic. Built for the Techfest 2026-27 "Cyborg-Themed Landing Page Development" task.

Concept

The page is built around one idea: the seam where human meets machine. The hero is a human eye and a mechanical eye split by a draggable seam. Human sections use a warm bone background, machine sections use cool steel.

Features
Draggable seam slider (mouse, touch and keyboard) comparing the human and augmented eye
Both eyes follow the pointer
Module picker (Optic, Grip, Link) with arrow-key navigation
Five-step process timeline, testimonial and a booking form with on-page confirmation
Fully responsive, visible keyboard focus, respects reduced-motion settings
Tech

Plain HTML, CSS and JavaScript in a single file. No build step and no dependencies apart from Google Fonts (Big Shoulders Display, IBM Plex Sans, IBM Plex Mono).

Run it

Open Main.html in a browser.
